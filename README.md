# Sistema de Ordem de Serviço - Oficina Mecânica

## Descrição

Este projeto foi desenvolvido para a disciplina de Banco de Dados.

O objetivo é modelar um sistema de gerenciamento de Ordens de Serviço para uma oficina mecânica, contemplando o modelo conceitual

## Entidades

- Cliente
- Veículo
- Ordem de Serviço
- Equipe de Mecânicos
- Mecânico
- Serviço
- Peça

## Ferramenta Utilizada

- MySQL Workbench
